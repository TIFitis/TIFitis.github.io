\section{Profile}
\begingroup\raggedright
Compiler engineer at AMD working on LLVM, MLIR, Flang, OpenMP target offload and AMDGPU code generation. I build correctness-critical compiler infrastructure where language semantics, IR lowering, runtime interfaces, memory lifetime and host/device data movement meet.

My recent work includes upstream LLVM changes for OpenMP data mapping, declare mappers, Fortran descriptor handling, GPU offload correctness, AMDGPU complex math lowering and runtime-facing code generation. I enjoy debugging subtle production compiler/runtime failures, designing maintainable abstractions in large C++ codebases, and turning complex specifications into robust generated code.
